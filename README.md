# Claude OS Starter

A shareable kit for building a personal "second brain plus assistant" on top of **Claude Code** — the
plan, the reasoning, copy-paste prompts, and templates to recreate it yourself.

## 👉 Start with [START-HERE.md](START-HERE.md)

This is **not an app or an installer.** It's the map and the prompts: you open Claude Code in a folder,
read a step, paste its prompt, and Claude Code builds that step *with* you. There's no code to install —
when a step needs a script or skill, Claude Code writes it.

Three honest stopping points (an afternoon, the 80/20, or the full always-on agent) and a clear build
order are explained in [START-HERE.md](START-HERE.md). Read that first.
